FLOWX UPDATE - CLIENT PC ONLY

=============================



1. Close Charts In Motion completely.



2. Extract the ZIP support sent you (folder like CiM-Update-1.0.2).



3. Put that folder inside your Charts In Motion UPDATE folder (no typing paths):

   D:\CiM\UPDATE\CiM-Update-1.0.2

   (Replace D:\CiM with your Charts In Motion install folder.)



4. Double-click Install-Client-Update.bat inside the extracted folder.
   Charts In Motion install is detected automatically from the UPDATE folder path.



5. Wait until it says update complete.

   Only if support told you to re-apply without re-running the bat:
   run Apply-Update.bat from the Charts In Motion install folder.



6. If license is missing, double-click Repair-CiMLicense.bat in the Charts In Motion folder.



7. Double-click start_cim.bat in your Charts In Motion folder.



Support needs if it fails:

- update-apply.log

- backend-startup.err.log

  (both in FlowX\runtime\logs\)
